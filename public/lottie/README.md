Déposez ici les animations téléchargées sur lottiefiles.com (format .lottie de préférence),
puis renseignez leur chemin dans `lib/site.ts` → `LOTTIE`.

- badge    : petite animation carrée (scan de QR code, ticket…) à côté de l'inscription à la newsletter
